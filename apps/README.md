# Applications

Runnable software lives under `apps/<app>/`, together with its configuration, tests, dependencies and operating instructions. Product research and experiments belong in `docs/product/`; installable agent skills remain in `skills/`.

[Discord](discord/README.md) contains a local prototype for on-demand reasoning, attributed capture, explicit endorsement and tree diagrams. Live configuration and a funded pilot remain separate steps. The main Reason Commons application remains in [Promise-Foundation/reason-commons](https://github.com/Promise-Foundation/reason-commons).

The browser demos are prebuilt static artifacts under `website/`; the app-era dashboard was retired on 2026-10-21. If application source with its own build and test lifecycle is introduced here, give that source an app home and publish its output deliberately; do not create a second manually maintained copy.
