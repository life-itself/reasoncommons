# Slides brief

Feeds the slide build (frontend-slides skill). This is the slide text, the builds, and the image asks. The spoken track is [`script.md`](./script.md); the slides are sparse against it. **Rule: the speaker carries the argument, the slide carries one image and one phrase.** If a slide needs a sentence read off it, it has too much on it.

`##` = section (doubles as a section-divider slide unless noted). `###` = one slide. Under each slide: **On slide** (exact text), **Build** (animation / transition, only where it does narrative work), **Visual** (image / screenshot / diagram). Live tool moments are marked `[LIVE]` with a static fallback noted.

## Theme and feel

- Start from the Life Itself warm-earth template: `~/src/life-itself/design/presentations/life-itself-warm-earth-reference.html`. Sand / clay / charcoal, Cormorant Garamond display + DM Sans utility, full-viewport slides. It already reads as Life Itself / Second Renaissance, so no new identity work.
- One accent colour (amber / signal, as in the explainer series), reserved for one meaning: *newly contributed or newly connected* — a card just placed, a node just edited, the condition nobody is holding. Never decorative.
- Mostly type on warm ground. The real tool (tree, reader) appears as live screen-share wherever room and tech allow; static screenshots are the fallback, captured in advance.
- Transitions are quiet: fades and simple builds. Two deliberate exceptions where the transition is the point: the opening question *evaporating*, and the pivot where the assumption *breaks*.
