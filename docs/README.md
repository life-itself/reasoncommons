# Project working material

Use these documents to develop the project. Publication is an explicit step into `website/`; a document being tracked here does not add it to the public site. This Git repository is public, so confidential material still belongs in its existing private location.

| Area | What belongs here |
| --- | --- |
| [Product](product/README.md) | User research, experiments, design and integration plans |
| [Marketing](marketing/README.md) | Positioning, outreach, editorial briefs and working scripts |
| [Business](business/README.md) | Public-safe business model, funding strategy and partnership work |
| `ltp_trees/`, `prompts/`, `references/` | Existing method references, source analyses, prompts and content-specific conversion helpers |
| [Beads and reasoning](beads-reasoning.md) | Collaboration handoff and coordination workflow |

Claims, endorsements and unfinished reasoning belong in the [shared collaboration model](../ltp/rufus-david-collab/reason-commons.yaml). Beads owns task status and ownership; GitHub issues own project-level planning. Keep application and skill operating instructions with the application or skill rather than duplicating them here.
