# Naming the tree

*Working memo — 1 September 2026. Companion to [`brand-and-domain-naming.md`](./brand-and-domain-naming.md). Scope: what we call the core object and its uses in everyday communication — not the site name (settled: "Reason Commons") and not the internal LTP tree names (Goal Tree, Current Reality Tree, etc.), which stay as jargon we don't put in front of people.*

## The object

One structure keeps recurring: a top-level claim — a goal, a thesis, or a question — recursively decomposed into the sub-claims it depends on, where the links between claims are themselves claims ("this one is necessary for that one"). We keep reaching for a name for it and using a different one each time. This settles on a small set.

## Candidates

| Term | Strengths | Weaknesses |
|---|---|---|
| **Tree of change** | Rhymes with "theory of change", which mission-aligned groups already say, so it lands with no explanation. Reads as forward-looking and purposeful. Pairs naturally with "tree of action". | Leans on the theory-of-change reading; slightly less apt for a tree that is a pure question decomposition with no goal at the top. |
| **Tree of action** | Clean sibling term for the work/plan side — actions hanging off the reasoning that motivates them. | Weak on its own; only makes sense next to "tree of change". |
| **Claim tree** / tree of claims | Precise: names the actual unit, a claim. Good internal and technical vocabulary; already used across `motivation.md` and `claim-tree-annotation.md`. | "Claim" reads as asserted and declarative (David's standing objection); cold for a general audience. Keep it backstage. |
| **Tree of thought(s)** | Generic, commits to nothing. | Vague — "thought" names nothing in particular. Collides with the "tree of thoughts" LLM-prompting technique, so it mis-cues anyone technical. Weakest option. |
| **Issue tree** | Established (Minto, consulting); precise for problem decomposition. | Consulting smell; "issue" sounds problem-only, not goals or theses. Fine to cite as heritage, not to adopt as our word. |

## Decision

- **Tree of change** — the primary, front-facing term, for the theory-of-change / thesis tree. When in doubt, this is the phrase.
- **Tree of action** — its sibling, for the plans and work that hang off the tree of change. Currently scoped as a follow-up (see the 2R talk).
- **Claim tree** — keep as internal and technical vocabulary for the generic object, consistent with the brand memo's line that "claim" stays as internal working vocabulary even though it is not the brand word.
- **Drop "tree of thought".** Vague, and it collides with an existing AI term.
- One phrase in front of an audience, not four.
