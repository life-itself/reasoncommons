You can now export an `.ltp.yaml` candidate as a standalone HTML dashboard and open it directly in the browser with the [`ltp-visualize` skill](https://github.com/life-itself/reasoncommons/blob/main/skills/ltp-visualize/SKILL.md). A local-server preview is available too; neither path changes the candidate or imports it into a Reason Commons space.
