Every pull request to this repository now says which part of our reasoning tree it serves and which tree updates it makes, and an automated check confirms that list against the tree, so work can't quietly drift away from the goal. The [`reason-commons` skill](https://github.com/life-itself/reasoncommons/blob/main/skills/reason-commons/SKILL.md) works the same way for any project that keeps its tree in its own repository, and a new [blog post](../blog/making-work-add-up.md) walks through how the change came about.
